# weather-backend
Calendar Backend written on Dart.

## Data sources

### Weather
Source is [WeatherApi](https://www.weatherapi.com).
You should pass `WEATHERAPI_TOKEN` environment variable to get access to it.

### Holidays
Source is [Wikipedia](https://wikipedia.org).

### Geomagnetic Kp index
Taken from [NOAA SWPC Planetary K-index API](https://services.swpc.noaa.gov/products/noaa-planetary-k-index.json)

### Background
Generated by Flux-1-schell model running in Cloudflare worker
